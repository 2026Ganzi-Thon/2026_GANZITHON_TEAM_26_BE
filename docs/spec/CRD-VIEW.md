## CRD-VIEW-001 기록 캘린더 조회

**트리거**
기록 캘린더 화면 진입

**사전조건**
로그인 상태

**입력**
- `yearMonth` (string): 조회할 연월, 필수

**처리 로직**
1. 해당 월의 날짜별 기록 존재 여부 조회

**출력**
기록 있는 날짜 목록

> 날짜를 눌렀을 때 "그날 남긴 것 있음/없음"은 이미 응답받은 날짜 목록으로 클라이언트가 판단한다(별도 API 호출 없음). 기록이 있으면 [[CRD-VIEW-002]]로 이동, 없으면 '아무것도 없음' 안내(2초)만 보여주고 목록을 띄우지 않는다.

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 400 | BAD_REQUEST | `yearMonth` 형식 불일치 |

## CRD-VIEW-002 그날 기록 목록 조회

**트리거**
기록 캘린더에서 기록 있는 날짜 클릭

**사전조건**
로그인 상태, 선택한 날짜에 기록 있음

**입력**
- `date` (date): 필수

**처리 로직**
1. 해당 날짜의 기록을 시각순으로 조회(기록 ID, 시각, 고른 감정, 사연 존재 여부만 — 사연 전체 내용과 받은 한 올 상태는 [[CRD-VIEW-003]]에서 조회)
2. 해당 날짜에 보낸 한 올이 있으면 '이날 누군가에게 N올을 건넸어요' 문구용 개수 조회([[SYS-STAT-001]] 하루 집계 기준), 없으면 문구 생략

**출력**
그날 보낸 개수(있을 때만 문구 노출), 기록 목록(기록 ID·시각·고른 감정·사연 존재 여부)

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 404 | NOT_FOUND | 해당 날짜 기록 없음 |
| 403 | FORBIDDEN | 타인의 기록 조회 시도 |

## CRD-VIEW-003 기록 상세 조회

**트리거**
그날 기록 목록에서 기록 줄 클릭

**사전조건**
로그인 상태, 해당 기록이 본인 소유로 존재함

**입력**
- `recordId` (long): 필수

**처리 로직**
1. 해당 기록의 고른 감정, 카드별 받은 한 올 상태(받음 → 메시지 / 안 누름 → '받지 않음' / 오늘 4번째 이후 선택 → '기본 위로') 조회
2. 사연이 있으면 전체 내용 함께 조회(없으면 사연 영역 자체를 노출하지 않음)

**출력**
고른 감정, 카드별 받은 한 올 상태(메시지 포함), 사연(있을 때만)

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 404 | NOT_FOUND | 해당 기록 없음(이미 삭제됨 포함) |
| 403 | FORBIDDEN | 타인의 기록 조회 시도 |
