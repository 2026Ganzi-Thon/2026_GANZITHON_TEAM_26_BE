# BLK-STACK 기능 명세

## BLK-STACK-001 담요 적립·완성

**트리거**
한 올 받기([[BLK-RCV-001]]) 완료

**사전조건**
로그인 상태, 오늘 1~3번째 기록으로 받은 한 올(실제 메시지 또는 대기열이 비었을 때의 기본 메시지) — [[BLK-RCV-002]](4번째 이상)는 담요에 적립하지 않으므로 이 기능을 타지 않는다.

**입력**
없음 ([[BLK-RCV-001]] 처리 결과를 받아 내부 처리)

**처리 로직**
1. 현재 담요의 채워진 칸 수를 확인하고 다음 칸 번호를 원자적으로 할당(카드 1·카드 2의 한 올이 [[BLK-RCV-001]] 한 응답에서 거의 동시에 적립되는 경우가 일반적이므로, "채워진 칸 수 확인 → 다음 칸에 적립"이 겹쳐서 같은 칸에 두 번 쓰이거나 칸이 건너뛰이지 않도록 사용자 단위로 순차 처리)
2. 받은 한 올(또는 기본 메시지)을 메시지·받은 일시와 함께 할당된 칸에 적립
3. 30칸이 모두 차면 현재 담요를 완성 처리하고, 다음 한 올부터는 새 담요(번호 증가)를 생성 — 30번째 칸 적립과 완성 처리도 한 번에 원자적으로 끝내 31번째 칸이 만들어지지 않게 한다

**출력**
적립된 칸 위치, 담요 완성 여부

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 409 | CONFLICT | 이미 30칸이 꽉 찬 담요에 중복 적립 시도 |
| 500 | INTERNAL_SERVER_ERROR | 적립 처리 중 오류 |
