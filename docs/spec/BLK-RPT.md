## BLK-RPT-001 한 올 신고

**트리거**
받은 한 올 카드에서 '신고' 클릭 후 확인 창에서 '신고' 선택

**사전조건**
로그인 상태, 실제 사용자가 보낸 한 올(오늘 1~3번째로 받은 한 올)

**입력**
- `yarnMessageId` (long): 신고 대상 한 올 메시지 ID, 필수

**처리 로직**
1. 신고 대상이 실제 사용자 발송 메시지인지 확인(기본 메시지는 신고 불가)
2. 신고 기록 저장(신고된 메시지, 발신자 해시, 신고 시각) — 신고 사유는 받지 않음
3. 해당 메시지를 즉시 숨김 처리 — "아직 숨김 처리되지 않은 경우에만" 조건으로 원자적으로 처리해, 같은 메시지를 두 사용자가 동시에 신고해도(해당 메시지를 1~2번째·2~3번째 카드 등으로 동시에 받은 경우) 교체가 두 번 일어나지 않게 한다. 두 번째 요청은 409로 처리
4. 같은 카드 자리에 같은 마음의 새 한 올을 대기열에서 꺼내 채움(대기열이 비었으면 기본 메시지), 담요 칸도 함께 교체

**출력**
숨김 처리 결과, 교체된 새 한 올(또는 기본 메시지)

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 404 | NOT_FOUND | 존재하지 않는 한 올 메시지 ID |
| 403 | FORBIDDEN | 본인이 받지 않은 한 올을 신고 시도 |
| 400 | BAD_REQUEST | 신고 대상이 기본 메시지(4번째 이후) |
| 409 | CONFLICT | 이미 신고 처리된 메시지 |

## BLK-RPT-002 보내기 제한
**추후 구현 - P1**

**트리거**
동일 발신자의 최근 30일 내 신고 누적이 3회에 도달하는 시점([[BLK-RPT-001]] 처리 중 내부 트리거)

**사전조건**
해당 발신자 신고 이력 2회 누적 상태에서 3번째 신고 발생

**입력**
없음 ([[BLK-RPT-001]] 처리 내부에서 판단)

**처리 로직**
1. 발신자 기준 최근 30일 내 신고 횟수 확인
2. 3회 도달 시 보내기 제한 해제 시각(현재 시각 + 24시간) 저장
3. [[BLK-SEND-001]] 보내기 가능 확인 처리 시 제한 여부와 해제 시각 확인, 제한 중이면 제한 안내 노출
4. 해제 시각 경과 시 신고 횟수 0으로 초기화, 제한 해제

**출력**
제한 여부, 해제 시각

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 403 | FORBIDDEN | 제한 중 보내기 시도 |
