# SYS-STAT 기능 명세

## SYS-STAT-001 하루 집계

> 원본 기능명세서 CSV의 트리거/사전조건/사용자시나리오 필드가 다른 기능 내용과 뒤섞여 있어, 데이터 목록표의 '하루 집계' 항목과 플로우차트를 기준으로 재구성했습니다.

**트리거**
마음 기록 저장 완료([[CRD-WRITE-003]]) 또는 패치 발송 완료([[BLK-SEND-002]]) 이벤트

**사전조건**
로그인 상태

**입력**
없음 (내부 이벤트 기반, 사용자 노출 없음)

**처리 로직**
1. 마음 기록 저장 완료 시 해당 날짜의 '고른 횟수' +1(원자적 증가)
2. 패치 발송 완료 시 해당 날짜의 '보낸 개수' +1(원자적 증가), 마지막 보낸 시각 갱신
3. [[CRD-DEL-001]]로 기록이 삭제되어도 날짜별 집계값은 변경하지 않음

**출력**
없음 (다른 기능에서 참조하는 집계값 갱신)

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 500 | INTERNAL_SERVER_ERROR | 집계 갱신 처리 실패 |
