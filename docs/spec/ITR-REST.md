# ITR-REST 기능 명세

## ITR-REST-001 함께 쉬는 방
**추후 구현 - P1**

**트리거**
'함께 쉬기' 선택(한 올 받기 완료 후) 또는 함께 쉬는 방 직접 진입

**사전조건**
로그인 상태, 한 올 받기 완료

**입력**
없음

**처리 로직**
1. 같은 시간대 입장자 수(채팅 없이 동시 접속 인원)를 익명으로 집계
2. 입장 시각 기준 15분 타이머 시작
3. '나가기' 클릭 또는 15분 경과 시 [[ITR-MAP-001]] 온기 지도 인원 표시 화면으로 이동

**출력**
동시 입장 인원(익명), 남은 시간

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 400 | BAD_REQUEST | 한 올 받기 미완료 상태에서 입장 시도 |
