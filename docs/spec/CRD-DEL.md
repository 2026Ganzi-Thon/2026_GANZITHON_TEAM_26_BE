## CRD-DEL-001 기록 지우기

**트리거**
기록 상세 화면에서 '이 기록 지우기' 클릭 후 확인 창에서 '지우기' 선택

**사전조건**
로그인 상태, 해당 기록이 본인 소유로 존재함

**입력**
- `recordId` (long): 삭제 대상 기록 ID, 필수

**처리 로직**
1. 해당 기록(및 사연)이 존재하는지, 본인 소유인지 확인
2. 그 기록 1건만 즉시 삭제(사연도 함께 삭제, 같은 날짜의 다른 기록에는 영향 없음)
3. 하루 집계([[SYS-STAT-001]])의 날짜별 횟수·담요 적립 상태는 변경하지 않음

**출력**
삭제 결과, [[CRD-VIEW-002]] 그날 기록 목록 화면으로 이동

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 404 | NOT_FOUND | 해당 기록 없음(이미 삭제됨 포함) |
| 403 | FORBIDDEN | 타인의 기록 삭제 시도 |
