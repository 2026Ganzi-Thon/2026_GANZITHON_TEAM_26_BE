## ITR-MAP-001 온기 지도 인원 표시

> "지금 같은 마음"과 "지금은 조용한 시간이에요"는 하나의 실시간 집계가 아니라 서로 다른 두 시간 범위 조회입니다. ① 최근 24시간 이내 집계, ② 24시간 초과~7일 이내 집계를 각각 쿼리해서, ①이 있으면 ①을, 없으면 ②를, 그마저 없으면 '첫 빛'을 보여주는 순서로 구현해야 합니다.

**트리거**
온기 지도 화면 진입

**사전조건**
로그인 상태, 오늘 기록 1건 이상

**입력**
없음 (오늘 고른 감정 기준)

**처리 로직**
1. 실시간 연결 상태 확인, 끊기면 상단 배너로 마지막 인원을 유지(재연결 시 자동 갱신)
2. 오늘 고른 감정이 1개면 해당 감정 인원, 2개면 두 감정 중 하나라도 고른 사람을 유저 ID 기준 중복 없이 합산
3. 최근 24시간 이내 같은 마음을 고른 인원이 있으면 "지금 N명이 같은 마음" 표시(5명 미만은 '몇몇 사람', 카드 2개면 두 마음 모두 표시)
4. 최근 24시간 이내는 없고, 24시간 초과~7일 이내 인원이 있으면 "지금은 조용한 시간이에요" + 지난 7일 인원 표시
5. 지난 7일에도 없으면(나뿐이면) "첫 빛" 문구 표시
6. 오늘 4번째 이상 기록이면 담요 미적립 안내를 추가 표시
7. 지도 집계용 기록(유저 ID·감정·시각)은 7일이 지나면 집계값만 남기고 삭제하는 게 맞지만, 그 정리 배치([[SYS-DATA-001]])는 추후 구현(P2)이라 지금은 원본이 계속 보관된다. 이 조회 로직 자체는 원본이 있든 집계값만 있든 동일하게 동작한다.

**출력**
인원 집계 문구, 담요 미적립 안내 여부

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 400 | BAD_REQUEST | 오늘 기록 없음 |
| 500 | INTERNAL_SERVER_ERROR | 인원 집계 조회 실패 |
