# CRD-WRITE 기능 명세

## CRD-WRITE-001 감정 선택
**BE 처리 없음 (프론트 로컬 상태)**

**트리거**
마음 고르기 화면에서 감정 도안 선택

**사전조건**
로그인 상태

**처리 로직**
1. 도안 선택·해제는 서버 호출 없이 화면 안에서만 처리한다.
2. 1~2개가 선택되면 '들어가기' 버튼을 활성화하고, 3개 이상은 선택 자체가 되지 않게 막는다.
3. 실제 유효성 검증과 저장은 '들어가기' 클릭 시 [[CRD-WRITE-003]](마음 기록 저장)에서 서버가 다시 확인한다.

**출력**
없음(화면 내부 상태 — 선택된 감정 목록, 들어가기 활성화 여부)

**예외 케이스**
서버 호출이 없는 화면 내부 상태 처리라 발생 가능한 예외가 없습니다.

## CRD-WRITE-002 사연 작성

**트리거**
사연 입력 화면에서 '저장' 클릭

**사전조건**
로그인 상태 (감정 선택은 필수 선행 조건 아님 — 사연을 먼저 작성한 뒤 감정을 고르는 순서도 허용)

**입력**

- `content` (string): 300자 이내, 선택 입력

**처리 로직**

1. '저장' 클릭 시 [[ALRT-DETECT-001]]로 위기 표현 검사
2. 위기 표현 없으면 사연 내용을 임시 보관(서버 저장은 [[CRD-WRITE-003]] '들어가기' 시점)
3. '취소' 클릭 시 작성 내용 폐기

**출력**
임시 보관된 사연 내용, [[CRD-WRITE-001]] 마음 고르기 화면으로 이동 안내

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 400 | BAD_REQUEST | 300자 초과 |

## CRD-WRITE-003 마음 기록 저장

**트리거**
마음 고르기 화면에서 감정 도안 1~2개 선택 후 '들어가기' 클릭

**사전조건**
로그인 상태

**입력**

- `emotions` (array): 1~2개, 필수
- `story` (string, optional): [[CRD-WRITE-002]]에서 임시 보관된 사연

**처리 로직**

1. 선택한 감정 개수 확인(1~2개만 허용, 3개 이상은 선택 자체가 불가해 서버까지 오지 않는 게 정상이나 방어적으로도 거부)
2. 존재하지 않는 감정 값인지 확인
3. [[ALRT-DETECT-001]]로 본문(사연 포함) 위기 표현 재검사
4. 오늘 같은 감정으로 이미 기록이 있는지 확인(30분 이내 동일 감정이면 시각만 한 줄 추가하고 지도 인원 집계는 그대로 / 그 외엔 새 기록 한 줄 추가 및 지도 인원 집계 반영) — '들어가기'를 빠르게 두 번 누르거나 네트워크 재시도로 같은 요청이 거의 동시에 들어와도 이 확인과 저장은 사용자 단위로 순차 처리해, 오늘 몇 번째 카운트와 지도 인원 집계가 중복 반영되지 않게 한다.
5. 날짜·시각, 고른 감정, 오늘 몇 번째인지와 함께 기록 저장
6. 하루 집계([[SYS-STAT-001]])의 날짜별 고른 횟수 +1
7. 사연이 포함되어 있으면 오늘 보낼 수 있는 개수([[BLK-SEND-001]]) 1개 추가 지급(상한 없음)
8. [[ITR-MAP-001]] 온기 지도 인원 표시 화면으로 이동

**출력**
저장된 기록, 오늘 몇 번째 기록인지, (사연 포함 시) 갱신된 오늘 보낼 수 있는 개수, [[ITR-MAP-001]] 온기 지도 인원 표시 화면 이동 안내

> 위기 표현 감지는 예외가 아닌 정상 분기로, 200 응답 후 본인에게만 위기 안내 화면([[ALRT-HELP-002]])으로 안내합니다(사연은 원래 흐름 유지).

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 400 | BAD_REQUEST | 감정 미선택 |
| 400 | BAD_REQUEST | 감정 3개 이상 선택 시도 |
| 400 | BAD_REQUEST | 존재하지 않는 감정 값 선택 |
| 500 | INTERNAL_SERVER_ERROR | 기록 저장 중 오류 |
