# BLK-VIEW 기능 명세

## BLK-VIEW-001 담요 조회

**트리거**
내 담요 화면 진입

**사전조건**
로그인 상태

**입력**
- `blanketId` (long, optional): 조회할 담요 번호, 미지정 시 현재 담요

**처리 로직**
1. 받은 패치 유무 확인, 없으면 빈 담요 안내
2. 있으면 해당 담요의 30칸 채움 상태 조회
3. 이전·다음 담요 번호로 넘겨보기 가능 여부 확인

**출력**
담요 번호, 30칸 채움 상태(메시지 유무), 이전/다음 담요 존재 여부

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 404 | NOT_FOUND | 존재하지 않는 담요 번호 조회 |
| 403 | FORBIDDEN | 타인의 담요 조회 시도 |

## BLK-VIEW-002 패치 카드 조회

**트리거**
담요의 채워진 칸 클릭

**사전조건**
로그인 상태, 채워진 칸

**입력**
- `blanketId` (long): 필수
- `slotIndex` (int): 1~30, 필수

**처리 로직**
1. 해당 칸의 메시지·받은 일시 조회
2. 받은 일시와 같은 날짜에 마음 기록이 있는지 확인, 있으면 '이날의 기록 보기' 노출([[CRD-VIEW-002]]로 연결)

**출력**
메시지, 받은 일시, 해당 날짜 기록 존재 여부

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 404 | NOT_FOUND | 빈 칸 조회 |
| 403 | FORBIDDEN | 타인의 담요 칸 조회 시도 |
