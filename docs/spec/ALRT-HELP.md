## ALRT-HELP-001 도움 요청

**트리거**
모든 화면 오른쪽 위 '도움 요청' 버튼 클릭

**사전조건**
없음 (모든 화면, 로그인 여부 무관)

**입력**
없음

**처리 로직**
1. 확인 창 없이 즉시 [[ALRT-HELP-002]] 위기 안내 전체 화면으로 전환(하단 탭 숨김)

**출력**
[[ALRT-HELP-002]] 위기 안내 화면으로 이동

**예외 케이스**

조건이 없는 단순 화면 전환이라 발생 가능한 예외가 없습니다.

## ALRT-HELP-002 위기 안내
**BE 처리 없음 (프론트 전용 화면)**

**트리거**
위기 안내 화면 진입([[ALRT-DETECT-001]] 또는 [[ALRT-HELP-001]]에 의해)

**사전조건**
없음

**처리 로직**
1. 상담 번호(프론트에 고정값으로 내장)를 표시한다. '번호' 클릭 시 클립보드 복사는 서버 호출 없이 화면에서 처리한다.
2. '한 올로 돌아가기' 클릭은 화면 전환만 담당한다 — 한 올 발송 보류 중 삭제된 글은 이미 [[BLK-SEND-002]]에서 위기 판정 시점에 삭제가 끝난 상태이고, 사연은 애초에 삭제 없이 저장 흐름을 탔으므로([[ALRT-DETECT-001]] 참고) 이 버튼 자체가 서버에 삭제를 요청하지는 않는다.

**출력**
없음(화면 내부 동작)

**예외 케이스**
서버 호출이 없는 화면 전환·클립보드 복사만 담당하므로 발생 가능한 예외가 없습니다.
