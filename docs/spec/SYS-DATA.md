## SYS-DATA-001 지도 원본 집계 전환
**추후 구현 - P2**

> 기능명세서의 "24시간 뒤" 삭제는 [[ITR-MAP-001]]의 '지금 같은 마음' 판단 기준(최근 24시간)과 혼동된 표현으로 보입니다. '지금은 조용한 시간이에요'(24시간 초과~7일 이내) 판단에 원본 데이터가 필요하므로, 데이터 목록표 기준대로 **7일 뒤 집계 전환**으로 확정합니다.

**트리거**
배치 스케줄러(매일 1회)

**사전조건**
지도 이벤트 원본(유저 ID·감정·시각) 존재

**입력**
없음 (배치)

**처리 로직**
1. 보관 기간 7일이 지난 지도 이벤트 원본 조회
2. 날짜·감정별 집계값만 남기고 원본(유저 ID 등 식별 가능 데이터) 삭제

**출력**
삭제·집계 전환 처리 건수

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 500 | INTERNAL_SERVER_ERROR | 배치 실행 중 오류(로그로만 기록, 사용자 노출 없음) |

## SYS-DATA-002 신고 데이터 파기
**추후 구현 - P2**

**트리거**
배치 스케줄러(매일 1회)

**사전조건**
신고 데이터 존재

**입력**
없음 (배치)

**처리 로직**
1. 신고 시각 기준 30일이 지난 신고·제재 데이터 조회
2. 해당 데이터 삭제

**출력**
삭제 처리 건수

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 500 | INTERNAL_SERVER_ERROR | 배치 실행 중 오류(로그로만 기록, 사용자 노출 없음) |
