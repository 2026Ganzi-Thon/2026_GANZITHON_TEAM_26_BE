# BLK-SEND 기능 명세

## BLK-SEND-001 보내기 가능 확인

**트리거**
보내기 화면 진입(보내기 탭 또는 패치 받기 화면에서)

**사전조건**
로그인 상태

**입력**
없음

**처리 로직**
1. 발신자 보내기 제한([[BLK-RPT-002]]) 여부 확인 — 제한 중이면 해제 시각과 함께 바로 응답, 질문 목록은 내려주지 않음
2. 제한 중이 아니면 작성 화면 표시, 대상 감정별 질문 목록(부족한 마음 우선 노출) 제공

**출력**
작성 가능 여부, 제한 중이면 해제 시각, 감정별 질문 목록(제한 중이 아닐 때만)

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |

## BLK-SEND-002 패치 검사·발송

**트리거**
작성 화면에서 '보내기' 클릭

**사전조건**
로그인 상태

**입력**
- `targetEmotion` (string): 대상 감정, 필수 (BLK-SEND-001에서 받은 질문 목록 중 선택)
- `content` (string): 1~50자, 필수 (대상 감정 질문에 대한 답 — 템플릿 선택 또는 직접 작성)

**처리 로직**
1. 발신자 보내기 제한([[BLK-RPT-002]]) 여부 확인, 제한 중이면 403
2. 마지막 발송 성공 시각 기준 5분 쿨타임이 지났는지 확인, 안 지났으면 429
3. 1차 금칙어(단어) 필터 통과 여부 확인
4. 2차 AI 분류로 위기/부적절/정상 판별([[ALRT-DETECT-001]] 연동)
5. 위기 판정 시 발송 보류, 작성 글 삭제 후 위기 안내 화면([[ALRT-HELP-002]])으로 이동
6. 부적절 판정 시 사유 안내와 함께 수정 요청, 작성 내용 유지
7. 정상 판정 시 발신자 해시(HMAC)와 함께 대기열에 등록, 대기 순서는 등록 시각 기준
8. 발송 완료 시 하루 집계([[SYS-STAT-001]])에 보낸 개수 반영

**출력**
발송 완료 여부(정상) / 수정 요청 사유(부적절) / [[ALRT-HELP-002]] 위기 안내 화면 이동 안내(위기)

> 위기 표현 감지는 예외가 아닌 정상 분기로, 200 응답 후 위기 안내 화면([[ALRT-HELP-002]])으로 안내합니다.

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 403 | CHEER_SEND_RESTRICTED | 신고 누적으로 보내기 제한 중 |
| 429 | CHEER_COOLDOWN | 마지막 발송 성공 후 5분이 지나지 않음 |
| 400 | INVALID_INPUT | 본문 길이 0자 또는 50자 초과 (Bean Validation) |
| 400 | INVALID_INPUT | 대상 감정 미선택 (Bean Validation) |
| 400 | CHEER_HARSH_LANGUAGE | 1차 금칙어 필터 또는 2차 AI 분류: 거친 말 |
| 400 | CHEER_DEMEANING | 1차 금칙어 필터 또는 2차 AI 분류: 누군가를 낮추는 말 |
| 400 | CHEER_HURTFUL | 2차 AI 분류: 받는 사람을 다치게 할 수 있는 말 |
| 400 | CHEER_DISMISSIVE | 2차 AI 분류: 아픈 마음을 작게 만드는 말 |
| 400 | CHEER_CONTACT_OR_LINK | 연락처·링크 포함 |
| 400 | CHEER_OFF_TOPIC | 2차 AI 분류: 패치와 맞지 않는 내용 |
| 500 | INTERNAL_SERVER_ERROR | 서버 전송 실패(작성 내용 유지) |
