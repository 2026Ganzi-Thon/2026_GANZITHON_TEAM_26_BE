# BLK-RCV 기능 명세

## BLK-RCV-001 한 올 받기

**트리거**
[[ITR-MAP-001]] 온기 지도 화면에서 '한 올 받기' 클릭

**사전조건**
로그인 상태, 오늘 1~3번째 기록

**입력**
없음 (오늘 고른 감정 카드 기준, 인증 토큰으로 사용자 식별)

**처리 로직**

1. 오늘 고른 감정 카드 중 1~3번째에 해당하는 카드만 이 기능에서 처리(4번째 이상인 카드는 [[BLK-RCV-002]]로 처리)
2. 카드별로 같은 마음 대기열에서 가장 오래 기다린 순으로 한 올 1건을 꺼내되, 본인이 보낸 한 올은 제외 — 같은 마음을 고른 다른 사용자들이 동시에 '한 올 받기'를 눌러도 대기열에서의 조회와 제거(꺼내기)를 한 번에 원자적으로 처리해, 같은 한 올이 두 사람에게 중복으로 지급되지 않게 한다
3. 대기열이 비어 있으면 기본 메시지로 대체(신고 대상에서 제외), 있으면 꺼낸 한 올 메시지를 그대로 사용
4. 어느 경우든(기본 메시지 포함) 담요에 1칸씩 적립([[BLK-STACK-001]])

**출력**
카드별 한 올 메시지 목록(카드 1 / 카드 2, 실제 메시지 또는 기본 메시지)

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 400 | BAD_REQUEST | 오늘 받기 가능한 기록 없음(마음 고르기 미완료) |
| 409 | CONFLICT | 이미 해당 기록으로 한 올을 받은 상태에서 재요청 |
| 500 | INTERNAL_SERVER_ERROR | 대기열 조회·적립 처리 실패 |

## BLK-RCV-002 기본 위로 받기

**트리거**
[[ITR-MAP-001]] 온기 지도 화면에서 '한 올 받기' 클릭

**사전조건**
로그인 상태, 오늘 4번째 이상 기록

**입력**
없음

**처리 로직**

1. 오늘 몇 번째 기록인지 확인, 4번째 이상이면 대기열 조회 없이 기본 메시지로 응답
2. 기본 메시지는 신고 대상에서 제외하고, 담요에는 적립하지 않음

**출력**
카드별 기본 메시지

**예외 케이스**

| Status Code | Status Name | Description |
| --- | --- | --- |
| 401 | UNAUTHORIZED | 로그인하지 않은 상태로 접근 |
| 400 | BAD_REQUEST | 오늘 기록 자체가 없어 몇 번째인지 판단 불가 |

## BLK-RCV-003 다음 행동 선택
**BE 처리 없음 (프론트 전용 화면 전환)**

**트리거**
한 올 받기 완료 후 선택지 화면에서 버튼 클릭

**사전조건**
로그인 상태, 한 올 받기 완료

**처리 로직**
1. '나도 한 올 보내기' 선택 → [[BLK-SEND-001]] 보내기 화면으로 이동
2. '다른 마음 고르기' 선택 → [[CRD-WRITE-001]] 마음 고르기 화면으로 이동
3. '함께 쉬기' 선택 → [[ITR-REST-001]] 함께 쉬는 방으로 이동(추후 구현, P1)

**출력**
없음(화면 이동만)

**예외 케이스**
서버 호출이 없는 화면 전환이라 발생 가능한 예외가 없습니다.
